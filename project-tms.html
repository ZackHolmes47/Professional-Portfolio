Ticket Management System Web Application

A full-stack ASP.NET MVC project focused on making ticket management easier to handle through clean CRUD workflows, structured data handling, and a more usable interface.

Back to Projects

Overview

A database-backed management build.

This project was built to create an organized way to manage ticket through structured workflows. The focus was on making the application feel clear and easy to use while keeping the backend logic clean and consistent with MVC design and database interaction.

It gave me hands-on experience connecting application logic, database operations, and front-end design into something that functions like a real business tool.

Tech Stack

Tools used in the build.

  • C#, HTML, and ASP.NET MVC handling application logic and flow.
  • Razor views for building the UI and user interaction.
  • SQL for structured, relational data storage.
  • Entity framework for managing database access and CRUD operations.
  • Cloud deployment to test the application in a live enviornment.
